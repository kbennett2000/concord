# Concord v1.3.1

A patch release. It cleans the text of the committed English translations. The API is unchanged: no endpoint, parameter or response key is added, removed or retyped.

```bash
docker pull ghcr.io/kbennett2000/concord:v1.3.1     # or :latest
docker run -d -p 8000:8000 ghcr.io/kbennett2000/concord:v1.3.1
```

## Broken and glued words repaired

The committed English translations carried word breaks from the text layer they were extracted from. KJV Genesis 6:14 read "in t he ark", and the same quirk appeared in every English translation except BSB. The breaks spoiled reading, and they hid words from keyword search and from the meaning-search embeddings.

This release makes **28,365 repairs in 12 translations** ([#91](https://github.com/kbennett2000/concord/pull/91)):

| Kind | Repairs | Example |
|---|---:|---|
| A word split by a stray space | 21,020 | "in t he ark" → "in the ark" |
| A stray space beside a hyphen | 7,240 | "sin- offering" → "sin-offering" |
| A space inside a possessive | 23 | "father’ s" → "father’s" |
| Two words run together | 15 | "himboth" → "him both" |
| No space after a sentence | 67 | "Damascus.Behold" → "Damascus. Behold" |

- **What a repair does.** It removes or inserts one space and nothing else. No wording, verse number or heading changes.
- **Evidence.** Each repair rests on the translation's own word counts and on the same verse in the other English translations.
- **Where to see them.** Every repair is listed in [`scripts/broken_words_manifest.csv`](https://github.com/kbennett2000/concord/blob/v1.3.1/scripts/broken_words_manifest.csv). Every case left alone for want of evidence is in [the `.md` beside it](https://github.com/kbennett2000/concord/blob/v1.3.1/scripts/broken_words_manifest.md). [`data/SOURCES.md`](https://github.com/kbennett2000/concord/blob/v1.3.1/data/SOURCES.md) records both cleanups applied to the committed text.
- **Untouched:** BSB, the SBL Greek NT and the Hebrew OT needed no repair.

**What you'll notice:**

- Search finds words it missed before. For example, WEB Exodus 26:18 now matches "tabernacle".
- Meaning-search scores move in the third decimal, because the WEB embeddings were rebuilt from the cleaned text.

**Caching.** Verse responses are served with `Cache-Control: immutable`. A client or proxy holding a response from an earlier version can keep serving the old text until its cache expires.

## For operators

The fix ships as a script, [`scripts/fix_broken_words.py`](https://github.com/kbennett2000/concord/blob/v1.3.1/scripts/fix_broken_words.py), which can also repair your own private translations:

- **It refuses some translations.** A translation whose notes are anchored by character position, a NET-style `char_offset`, is never changed.
- **`--dry-run`** reports what it would do and writes nothing.
- **`--kinds`** limits a run to one kind of repair.

A new guard test, `bible-core/tests/test_no_broken_words.py`, fails if a broken word comes back in the committed text.

See [`docs/API.md`](https://github.com/kbennett2000/concord/blob/v1.3.1/docs/API.md) for the full reference.
